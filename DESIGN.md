# Surya Digital Laboratory — Visual Identity

## North Star: "The AI Builder's Workspace"
A technical, high-fidelity environment that feels like a custom-built data console. Precision-engineered whitespace, monospaced metadata, and editorial-scale typography.

## Visual Motif: "Data Flow"
Thin, glowing 1px lines (Electric Cyan and Magenta) that interconnect sections, representing neural pathways and data pipelines.

## Design Principles:
1. **Oversized Typography:** Hero text as a structural element.
2. **Technical Brutalism:** Sharp corners (rounded 4px max) and thin borders instead of soft cards.
3. **Information Density:** High-fidelity project mockups with realistic UI elements (charts, code snippets, metrics).
4. **Selective Glow:** Radiance is reserved for primary CTAs and active data nodes.
